**Pre-release.** Manual install only (Load unpacked); not yet in the Chrome Web Store or Edge Add-ons, and no automatic updates. Installation steps are in `INSTALL.md` inside the zip.

### What's new in 1.1.0

- **English and Chinese interface.** All UI text, notifications and keyboard-shortcut descriptions follow the browser language (English, or Simplified Chinese for `zh-CN` browsers).
- **Site icons without network requests.** Icons are read from the browser's local favicon cache (`_favicon`). Showing tabs and quick links no longer contacts websites or icon services. This adds the `favicon` permission.
- Bookmark-folder suggestions and page categories work in both languages.

### Upgrading from 1.0.x

Export your data in settings first. Then replace the files in the folder you originally loaded and click **Reload** on the extension page. Don't uninstall, and don't load it from a different folder: the extension ID would change and local data would be lost.
