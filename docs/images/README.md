stretched portrait images. The quick-links examples contain nine links in one workspace category

All titles, links, categories, tabs, bookmarks and archives are **synthetic**. Links use the
reserved example.com, example.org and example.net domains. No personal browser profile, open
tabs, browsing history, credentials or private notes were used. Browser APIs were simulated;
these images demonstrate the actual components, not an installed-extension runtime test.

The fixture used the repository's own icon and built-in styling, with no remote wallpaper,
quotes, model calls or desktop App connection. Capture helpers are not part of the extension
or the public distribution. Images are browser captures, not AI-generated interface mockups.
